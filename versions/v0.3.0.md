# AutoPPT 0.3.0

本版將對話、研究、素材與產出流程整合成可持續協作的簡報工作室。

- 預設使用最新模型；既有手動設定的模型會保留，也可在設定中更新模型列表。
- 預設為全局對話，可直接要求修改整份簡報；需要時可切換為單頁對話。
- AI 會在需要時自行進行網頁研究、搜尋內建或使用者素材庫，並可在需要時生成圖片。
- 可建立自己的素材庫、匯入必須使用的圖片，並保留素材來源資訊。
- 每頁可編輯或由 AI 生成簡短講稿；完成後可重新生成整份簡報。
- 「我的專案」新增刪除專案功能。
- 啟動時先顯示準備畫面，再檢查 PowerPoint 與服務狀態。
- 更新流程保留既有專案與設定，並使用本倉庫的 `latest.yml` 與 blockmap。

## 安裝

下載 `AutoPPT-Setup-0.3.0.exe` 並在 Windows x64 安裝。需要 Microsoft PowerPoint；原生 SmartArt 功能另需 Microsoft Excel 元件。AI 功能需要使用者自行填入供應商 API Key，相關模型與圖片 API 費用依供應商計算。

安裝程式目前未簽章。可用同版 `.sha256` 檔檢查安裝檔完整性；`.blockmap` 與 `latest.yml` 供程式內更新使用。

## 驗證

本版已在 Windows、PowerPoint 16、Excel 16 環境完成 bridge、打包版、UI、素材、設定恢復、更新流程與端到端 pipeline 驗證。模型生成品質仍取決於使用者的模型供應商、權限與提示內容。
