# AutoPPT v0.6.1

本版修正內容大綱的 JSON 解析失敗，並包含新的製作引擎與更新體驗。

- 大綱可辨識模型回應中的 Markdown、說明文字及常見外層包裝。格式有誤時會顯示進度並自動修正一次；失敗或取消保留原大綱與講稿，不保存截斷的頁面。
- 研究達到輪數上限後，會要求模型依現有資料輸出完整大綱，避免把尚未產生的內容判定為 JSON 錯誤。
- 修正搜尋服務回傳相對網址或重新導向網址造成大綱 `Invalid url` 的問題。
- 大綱與逐頁設計顯示實際模型串流、已收到的頁數、目前主張與驗證階段。
- 新製作使用完整 SVG 自由構圖，透過 ppt-master 轉成可編輯 PowerPoint 文字與圖形，再由 PowerPoint 渲染檢查。大綱依內容關係決定視覺，不強制固定版面種類配額。
- 製作通過品質檢查後直接進入「檢視與調整」，可在該頁透過對話修改；單頁 SVG 修改先讀取原構圖。
- 保留啟動時自動檢查與下載更新；下載完成後，由使用者選擇「重新啟動並安裝」。安裝時顯示進度，完成後自動啟動。
- 原有簡報保留既有修改方式；重新生成或因內容／風格變更而重建時使用新製作路徑。

需求：Windows x64 與 Microsoft PowerPoint。原生 SmartArt 另需 Microsoft Excel。AI 功能需自己的供應商 API Key；簡報視覺生成需使用支援圖片輸入的模型。安裝包包含 .NET、LiteLLM 與 SVG 轉換器，不需另裝 Python。

更新保留專案、加密設定及恢復備份。0.5.0 首次升級仍由舊版的自動安裝流程控制；新版的安裝時機選擇在升級後生效。0.1.0 沒有自動更新，需手動下載安裝。安裝程式目前未簽章。

SVG 路徑使用 ppt-master 的原生轉換核心，未移植全部模板、動畫、旁白、母片及原生資料圖表／表格介面。SVG 圖表以可編輯形狀呈現；既有 COM 圖表與 SmartArt 保留在舊專案路徑。

驗證使用受控模型回應、實際 Electron 與 PowerPoint；沒有以付費模型評估生成品質，也未實際執行跨版本安裝／解除安裝。0.6.0 為未發布的本機候選版本，公開更新由 0.5.0 直接升至 0.6.1。
