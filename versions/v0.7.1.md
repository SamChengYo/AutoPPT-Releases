# AutoPPT v0.7.1

本版修正視覺風格的設計規劃格式錯誤，以及規劃中切換頁面後無法直接返回的問題。

- 設計規劃可辨識 JSON 前後的說明文字、Markdown 程式碼區塊與 designPlan 外層包裝。模型輸出欄位型別、長度或頁數不符時，自動要求修正一次，畫面顯示修正進度。
- 規劃提示明確指定字級數值、文字欄位、圖片 ID 與長度限制。仍失敗時顯示具體欄位原因；不儲存截斷內容，也不以部分頁面覆寫原規劃。
- 規劃期間可從「我的專案」或「模型與設定」直接點左側「視覺風格」返回，也可使用目前專案卡片或進度列的返回按鈕。返回不會重新呼叫模型或覆寫規劃結果。
- 停止設計規劃會顯示正確的停止訊息，保留原規劃與設計檔案。

下載 `AutoPPT-Setup-0.7.1.exe`，或使用程式內更新。既有專案可直接重試「規劃逐頁設計／重新規劃設計」。更新保留專案、加密設定及恢復備份。

需要 Windows x64、Microsoft PowerPoint，以及使用者自己的模型 API Key。安裝包包含 .NET、LiteLLM 與 SVG 轉換器，不需另裝 Python；安裝程式未簽章。

驗證包含單元測試、受控模型的格式修正／失敗／取消保留原稿、真實 Electron 的長時間規劃切頁往返，以及正式打包版。未使用付費模型評估生成品質，未實際執行跨版本安裝／解除安裝。格式修正最多增加一次模型請求，費用依供應商計算。
