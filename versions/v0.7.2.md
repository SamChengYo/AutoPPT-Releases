# AutoPPT v0.7.2

本版改善大綱與視覺設計的等待時間，並加入生成診斷紀錄。

- 4 頁以上的新大綱及視覺設計先建立全篇方向，再由最多三組模型工作者並行處理，每組最多三頁，最後由主編／美術指導核對整體並提出必要修正。
- 取消或分組失敗時停止其他進行中的請求，並保留既有大綱、設計規劃與設計檔。
- 單次模型請求最多 10 分鐘；連續 3 分鐘沒有收到資料才視為停滯。大綱生成整體時限延長為 10 分鐘。
- 「模型與設定」新增診斷紀錄入口，可檢查作業階段、模型請求耗時、分組與錯誤分類。日誌不記錄 API Key、提示詞或簡報正文。

下載 `AutoPPT-Setup-0.7.2.exe`，或使用程式內更新。更新保留本機專案與設定。需要 Windows x64 與 Microsoft PowerPoint；安裝程式包含 .NET、LiteLLM 與 SVG 轉換器，不需另裝 Python。安裝程式未簽章。
