# AutoPPT v0.9.1

本版修正大綱生成遇到模型輸出長度上限時直接失敗的問題。

- 大綱初稿與自動修正超限時，沿用原始需求與已核對研究，自動拆成較小批次，必要時逐頁處理；保留指定總頁數、頁序與封面／結尾角色。
- 分頁講稿與全篇審查也能自動縮小失敗範圍，成功的批次不重送，仍產生完整講稿。修改既有大綱時保留目前頁數。
- 介面顯示自動分批進度。取消、持續失敗或拆至單頁仍超限時保留原大綱與講稿，不儲存截斷內容，也不無限重試。
- 串流及非串流回應均辨識輸出超限，避免將未完成的 JSON 或工具參數當成有效結果。診斷紀錄新增輸出超限分類，不記錄簡報內容或 API Key。

驗證包含 117 項測試及真正 Electron／preload／IPC 介面。受控模型連續觸發大綱、講稿及審查超限，仍完成指定頁數；測試涵蓋 3 頁、40 頁、自動頁數、首尾角色、講稿、研究沿用、取消與原稿保留。

正式打包版另以串流長度終止訊號驗證 14 頁大綱、完整講稿與首尾角色恢復；實際 PowerPoint 模板／SVG 編輯、設定恢復及舊專案保留均通過。測試使用隔離資料，不影響正在使用的專案。

自動分批可能增加模型請求，共用原本 10 分鐘作業時限；未指定頁數且首次產出截斷時，以 8 頁恢復，符合原有自動範圍。未使用付費模型評估各家成功率；未實際驗證跨版本安裝／解除安裝。

安裝 `AutoPPT-Setup-0.9.1.exe`，或使用程式內更新。既有專案可直接重試大綱，不需刪除專案。更新保留專案、加密設定與恢復備份；0.1.0 首次需手動安裝。

需要 Windows x64、Microsoft PowerPoint 與使用者自己的模型 API Key。安裝包包含 .NET、LiteLLM 與 SVG 轉換器，不需另裝 Python；安裝程式未簽章。
