# AutoPPT 0.4.0

## 啟動與更新

- 開啟 App 後，在專用啟動頁自動檢查版本、下載更新並顯示進度。下載及完整性驗證完成後，自動關閉程式、靜默安裝並重新啟動，不需操作更新安裝精靈。
- 連線失敗可重試或先進入工作室；版本檢查超過 20 秒時提供離線進入選項。預設來源仍為公開 AutoPPT-Releases。
- 0.3.0 與更早版本仍使用舊 updater，第一次升到本版可能仍出現舊安裝流程。新啟動器負責本版之後的更新。首次安裝仍需下載安裝檔；Windows 視安裝權限可能顯示系統授權提示。

## 模型、大綱與對話

- OpenAI、Google Gemini、Anthropic、DeepSeek 各自同步所有已填 Key 的供應商，不受啟用開關影響；同步前先儲存畫面上的新 Key。逐家顯示成功、缺 Key 或錯誤，不再把部分失敗說成全部成功。
- 修正 Gemini 能力欄位，支援 Gemini／Anthropic 模型清單分頁，移除前 60 筆截斷。文字模型選單排除不適用的專用嵌入／影音模型；可用性仍由帳戶權限決定。
- 取消啟動後在背景重啟模型服務的競爭情況。大綱生成顯示階段與等待時間，可停止，四分鐘逾時保留原稿；等待中可查看專案列表與設定。
- 對話區改為完整訊息介面：專案脈絡、全局／單頁範圍、時間、修改紀錄、處理狀態、快捷建議、歷史載入與可預先撰寫的輸入框。

## 視覺與內容

- 參考 [ppt-master 技術設計](https://github.com/hugohe3/ppt-master/blob/main/docs/technical-design.md) 的敘事規劃、視覺設計與品質檢查分工，維持 AutoPPT 自己的 Office 原生生成流程。
- 新增可編輯的圖文故事、關鍵數字、決策矩陣與行動路線圖，共 17 種版面。
- 每頁可編輯視覺構圖與證據來源。模型先安排主張、支撐、視覺焦點與講稿；六頁以上的初次大綱檢查版面多樣性與構圖描述，必要時修正一次，仍不合格則保留原稿供重試。

## 安裝與資料

下載 AutoPPT-Setup-0.4.0.exe。需要 Windows x64 與 Microsoft PowerPoint；SmartArt 另需 Excel。模型與圖片費用由使用者自己的 API 帳戶支付。

更新保留專案、素材與加密設定；解密失敗保留原檔與恢復備份，不阻擋整個程式啟動。安裝檔目前未簽章。

## 驗證範圍

已驗證核心測試、啟動器／對話／取消大綱的受控 UI、模型清單分頁與部分失敗、設定恢復，以及真實 Office 的 17 種版面。同一份 Windows 安裝包已通過打包版與更新來源設定檢查。

生成流程使用受控模型回應，未使用真實付費 API 驗證內容品質；最終生成效果仍受模型能力與素材品質影響。靜默安裝參數及流程已受控驗證，未對使用者現有安裝執行跨版本升級，亦未實際解除安裝。
