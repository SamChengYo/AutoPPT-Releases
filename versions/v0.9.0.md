# AutoPPT v0.9.0

本版新增使用自己的 PPT 模板製作簡報，並改善對話進度、工具紀錄與模型設定回饋。

- 素材準備保留一般素材上傳，新增獨立 PPT 模板上傳，只接受 `.ppt`／`.pptx`（最大 50MB、1–40 頁）。提供頁面預覽、更換與移除，移除免費素材庫、圖片搜尋與 AI 生圖入口。
- AI 將模板納入大綱與設計規劃，依大綱複用模板頁，在專案副本修改既有文字及物件，沿用原始尺寸、母片、版面、字體與配色，保留原檔。製作中斷後可繼續；沒有實際修改模板頁面時不會標示完成。
- 對話與展開的製作紀錄在底部時自動跟隨新內容；往上捲後保留閱讀位置，顯示回到底部箭頭。
- 工具紀錄預設收合，只顯示最新操作及執行中／完成／失敗狀態；展開可查看完整工具參數與結果。
- 模型設定提供儲存與連線測試成功／失敗提示，也清楚區分已儲存但測試失敗，以及部分模型清單同步失敗。

驗證包含 104 項測試、真正 Electron／preload／IPC 介面及實際 PowerPoint。模板測試涵蓋 `.ppt`／`.pptx` 匯入、4:3 原始尺寸、頁面複用、群組文字、字體與位置保留、中斷後繼續及 PPTX／PDF 匯出；來源檔案雜湊保持一致。模型回應使用受控測試，未使用付費模型評估任意模板的內容或美感。

正式打包版另驗證內附模板服務與 Office bridge、原生／群組文字編輯、原始設計保留、每頁完成判定、既有專案與無法解密設定保存，以及 SVG 首尾修改與正文保留。

模板中的文字需為可編輯物件；圖片內文字不會自動轉為文字框。更換或移除模板後需重新規劃與重建。未實際驗證跨版本安裝／解除安裝。

安裝 `AutoPPT-Setup-0.9.0.exe`。更新保留使用者專案、加密設定與恢復備份；0.1.0 首次需手動安裝。

需要 Windows x64、Microsoft PowerPoint 與使用者自己的模型 API Key。安裝包包含 .NET、LiteLLM 與 SVG 轉換器，不需另裝 Python；安裝程式未簽章。
