# AutoPPT v0.8.1

本版修正檢視階段的 AI 對話修改、Enter 送出行為，並強化封面與結尾的設計要求。

- 全局與指定頁對話會實際修改既有投影片，保留檢視畫面、進度及停止入口。成功會回報修改頁碼並更新預覽；失敗或取消也會留下回覆及修改要求。
- AI 只宣告完成、只檢查截圖或原樣重送時，不會標示修改成功。修改需有實際編輯及前後預覽差異；重試後仍未變更會清楚回報失敗並保留簡報。
- 對話框與單頁修改框以 Enter 送出、Shift + Enter 換行；中文輸入法選字／確認不會誤送。
- 封面以主題標題、副標與主題主視覺建立開場；結尾以設計過的 The End／結束語、核心結論及呼應封面的視覺收束。舊大綱也依首尾位置安排角色，不增加頁數。SVG 製作入口拒絕只有標題或背景的首尾。

驗證包含 100 項測試、真正 Electron／preload／IPC 介面、受控模型搭配真正 PowerPoint、全局及單頁修改、原樣重送不得完成，以及 PNG／PPTX／PDF 匯出。正式打包版另驗證首尾修改、正文保留、對話回饋、原樣重送不得完成與隔離測試資料保留；四個發布附件的雜湊及更新資訊已核對。

本次未使用付費模型評估首尾美感；首尾結構檢查不等同模型設計品質保證。未實際驗證跨版本安裝／解除安裝。

安裝 `AutoPPT-Setup-0.8.1.exe`。更新保留使用者專案、加密設定與恢復備份；既有簡報需提出修改或重新生成後才會套用首尾設計規則。

需要 Windows x64、Microsoft PowerPoint 與使用者自己的模型 API Key。安裝包包含 .NET、LiteLLM 與 SVG 轉換器，不需另裝 Python；安裝程式未簽章。
