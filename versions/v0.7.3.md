# AutoPPT v0.7.3

本版改善大綱與視覺設計規劃速度，並修正製作流程中預覽延遲、SVG 匯入失敗及錯誤顯示完成的問題。

- 大綱與視覺設計最多可同時處理五組頁面；每組最多三頁，最後仍會檢查全篇一致性。
- 製作流程提早顯示第一張 PowerPoint 預覽，分批更新頁面，並清楚顯示已產生、已通過版面檢查與目前檢視的頁數。缺頁、錯誤或品質檢查未完成時，不會標示整份簡報已完成。
- 改善 SVG 箭頭、版面註記與文字邊界處理；自動修正時會提供 Office 實際測得的物件與文字位置。連續工具失敗時會明確顯示錯誤並保留已產生頁面。
- 診斷紀錄顯示模型回合與工具耗時，不包含 API Key、提示內容或完整模型回覆。

**實測結果：**在同一份核准的 11 頁設計與真正 PowerPoint 下，GPT-6 Luna 首張預覽約 27 秒、全部 11 頁約 3 分 14 秒，完成檢查約 3 分 42 秒；Claude Sonnet 5 首張預覽約 1 分 51 秒、全部 11 頁約 8 分 45 秒，完成檢查約 8 分 49 秒。這是各一次的實測，不代表固定速度或品質保證。Claude Sonnet 5 的另一次完整大綱／設計流程在最後的整體設計審查請求停滯並逾時，沒有開始製作；使用不同模型與服務時，完成時間和成功率會不同。

驗證包括 81 項測試、實際 Electron 介面、Office COM／SVG／受控模型整合，以及使用付費 API 與真正 PowerPoint 的實測。指定模型的完整流程與 11 頁相同輸入製作測試結果已區分記錄；未宣稱所有模型都能成功完成規劃。未實際驗證跨版本安裝／解除安裝。

下載 `AutoPPT-Setup-0.7.3.exe`，或使用程式內更新。更新保留使用者專案、加密設定及恢復備份。

需要 Windows x64、Microsoft PowerPoint，以及使用者自己的模型 API Key。安裝包包含 .NET、LiteLLM 與 SVG 轉換器，不需另裝 Python；安裝程式未簽章。規劃與製作的模型請求數及費用會依模型、頁數與修正次數而變化。
