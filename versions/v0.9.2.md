# AutoPPT v0.9.2

本版修正設計規劃一次處理整份簡報，容易達到模型輸出長度上限的問題，改為一頁一頁完成。

- 先取得精簡的共用風格，再依序設計當頁、審查當頁，完成後才處理下一頁。每次只送當頁大綱、講稿、相關素材與對應模板頁，保留全篇頁碼及封面／結尾角色。
- 共用風格、單頁設計或審查超限時，以精簡輸出重試一次；已完成頁面不重送，截斷內容不當成有效設計。取消或單頁仍失敗時，保留原規劃與設計文件。
- 介面依完成頁數顯示進度；整份規劃通過頁數、順序、圖片與模板檢查後才儲存並開放核准。修改講稿後需重新核准設計。
- 保留 0.9.1 的大綱、講稿與審查輸出超限恢復功能。

驗證包含 125 項測試及真正 Electron／preload／IPC 介面。受控模型涵蓋 1、3、40 頁循序處理、當頁輸入隔離、格式修正後再超限、重試上限、取消、原規劃保留與講稿核准失效。

正式打包版另驗證模型串流超限恢復、14 頁大綱與完整講稿、實際 PowerPoint 模板／SVG 編輯、設定恢復及舊專案保留。測試使用隔離資料，不影響正在使用的專案。

逐頁處理可能增加請求數及總耗時，仍共用原本 10 分鐘作業時限；單頁仍超限時保留原稿並回報錯誤。未使用付費模型評估各家成功率，未實際驗證跨版本安裝／解除安裝。

安裝 `AutoPPT-Setup-0.9.2.exe`，或使用程式內更新。既有專案可直接重試設計規劃，不需刪除專案。更新保留專案、加密設定與恢復備份；0.1.0 首次需手動安裝。

需要 Windows x64、Microsoft PowerPoint 與使用者自己的模型 API Key。安裝包包含 .NET、LiteLLM 與 SVG 轉換器，不需另裝 Python；安裝程式未簽章。
