# AutoPPT 0.5.0

本版修正輸入與刪除專案問題，並加入參考 ppt-master 的設計規劃與品質檢查流程，供實際製作測試。

## 更新重點

- 刪除確認改為程式內對話框，改善 Windows 原生確認視窗後輸入欄位失去焦點的問題；新增專案完成初始化後才開放編輯，忙碌欄位明確停用。
- 刪除專案後清除目前草稿，並拒絕延遲儲存把已刪專案重新建立；重新啟動後也保留此保護。
- 製作前先規劃整份簡報的敘事、視覺語言、字級及逐頁構圖，檢視並確認後再開始製作；內容或風格變更後會要求重新規劃。
- 新增工程藍圖、企業簡報風格，以及自由畫布、編號目錄與雙指標版面。AI 可用原生文字框、線框與連線建立構圖。
- 完成與匯出前檢查文字溢出、文字框重疊、畫布越界、圖片佔位框及頁數；未通過會要求修正並保留進度。

## 建議測試

1. 新增專案並連續打字，取消刪除後再編輯；確認刪除後切換頁面、重新啟動，專案不會復活。
2. 完成大綱後，在「視覺風格」選擇風格，按「規劃逐頁設計」，檢視構圖後按「確認設計並開始製作」。
3. 使用自己的視覺模型生成簡報，檢查逐頁預覽、講稿與可編輯的 PPTX。舊專案第一次重新製作前也需完成設計規劃。

## 安裝與驗證範圍

下載 `AutoPPT-Setup-0.5.0.exe`。需要 Windows x64 與 Microsoft PowerPoint；原生 SmartArt 另需 Excel。AI 功能需自行設定 API Key。安裝程式目前未簽章。

更新保留專案、素材與加密設定。0.4.0 起可透過啟動更新流程取得新版；0.1.0 使用者需手動安裝。

已完成核心測試、Electron 操作回歸、實際 Office 繪圖與端到端流程驗證。模型流程使用受控回應，視覺樣本使用固定測試內容；尚未以真實付費模型驗證生成美感，也未宣稱已達到 ppt-master 範例品質。程式檢查不能取代內容與視覺審閱。未實測使用者現有安裝的跨版本升級。

製作流程參考 [ppt-master](https://github.com/hugohe3/ppt-master)，AutoPPT 仍使用原生 Office 製作引擎，未完整移植上游 SVG 編譯器或品牌模板系統。
