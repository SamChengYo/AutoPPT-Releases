# AutoPPT 0.2.1

本版改善流程記憶、視覺生成、素材取得與 Windows 背景執行。預設更新來源為公開 AutoPPT-Releases 版本庫，原始碼另以私人倉庫管理。

- 確認主題直接進入下一步；走過的步驟可直接往返，表單、搜尋、風格、大綱與逐頁修改草稿會保存。
- 第一次進入內容大綱時自動請 AI 建議；已有大綱不會因返回而被覆蓋。
- 加入 AI 圖片生成、Wikimedia Commons 圖片搜尋、網頁研究與 24 款附授權的離線圖示。
- 13 種版面、原生可編輯 SmartArt、圖案與圖表，並要求模型依內容安排不同版型。
- 切換視覺風格會更新同一專案的簡報，保留原專案身分並重建符合所選配色的內容。
- PowerPoint 與 SmartArt 使用的私人 Excel 在背景執行；進度、截圖與工具操作顯示在 AutoPPT。
- 加入程式內檢查更新、背景下載、重新啟動安裝與解除安裝入口；更新來源預設 GitHub Releases，也可改為 HTTPS 目錄。
- 修正舊設定無法解密造成的啟動失敗：保留原加密檔與備份，開啟程式並提示重新設定 API Key，專案保留。

## 安裝與更新

下載 `AutoPPT-Setup-0.2.1.exe`。0.1.0 尚無內建更新，第一次需安裝此版；往後可在「模型與設定」更新。需要 Windows x64 與 Microsoft PowerPoint；原生 SmartArt 另需 Excel 元件。

若出現設定恢復提示，請重新填入自己的 API Key。圖片生成及文字模型費用由供應商依用量計算；Wikimedia 搜尋與離線圖示不需要模型 Key。素材來源與授權會隨匯出產生 credits 檔。

## 驗證

已在本機使用真正 PowerPoint / Excel 驗證版面、SmartArt、圖表、背景執行、PPTX/PDF、同專案換風格與 UI 流程。模型流程使用受控回應，未使用真實付費模型驗證生成品質。安裝程式目前未簽章。
