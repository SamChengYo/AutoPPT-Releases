# AutoPPT v0.8.0

本版加入指定頁數、首尾設計與完整報告講稿，並讓模型清單在尚未填入 API Key 時也能自動更新。

- 主題頁可指定 3–40 頁總頁數，包含封面與結尾；也可由 AI 自動安排 6–12 頁。大綱不符指定頁數或缺少首尾角色時，自動修正一次，失敗或取消保留原稿。
- 封面與結尾都納入逐頁視覺設計，包含主視覺、結論與行動建議。正文增加具體說明、例子與圖解；每頁講稿以實際報告為目標，正文建議 300–500 個中文字、首尾 150–250 字，依簡報語言生成並保存在 PowerPoint 備註。
- 一般介面、生成進度與模型輸出以 AutoPPT 呈現，移除參考引擎署名；第三方授權與來源紀錄保留。
- 啟動及檢查更新時自動同步模型。尚未填 Key 時取得官方公開清單，有 Key 時核對帳戶模型；離線或失敗保留快取。清單同步不重啟模型服務，也不覆蓋未儲存的設定。
- 預設模型改為 OpenAI `gpt-6-luna`、Anthropic `claude-opus-5-5`、Gemini `gemini-3.8-flash`。舊的未固定預設會遷移，使用者固定或自訂的模型保留。公開清單不代表帳戶有權使用所有模型。

驗證包括 91 項測試、真正 Electron／preload／IPC 介面、設定加密與恢復、受控模型搭配真正 PowerPoint、SVG／PPTX／PDF 匯出，以及無 Key 連線官方模型清單。正式打包版另驗證內附服務、既有專案保留及公開更新來源。此次未呼叫付費模型評估新版講稿品質與首尾美感，未實際驗證跨版本安裝／解除安裝；模型輸出仍受供應商能力影響。

下載 `AutoPPT-Setup-0.8.0.exe`，或使用程式內更新。更新保留使用者專案、加密設定及恢復備份。建議建立新專案體驗指定頁數與首尾設計；既有專案可重新規劃大綱與視覺設計。

需要 Windows x64、Microsoft PowerPoint，以及使用者自己的模型 API Key。安裝包包含 .NET、LiteLLM 與 SVG 轉換器，不需另裝 Python；安裝程式未簽章。模型請求數及費用會依模型、頁數與修正次數而變化。
