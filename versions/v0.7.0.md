# AutoPPT 0.7.0 — PPT-Master 設計核心與批次生成

下載 [AutoPPT v0.7.0](https://github.com/SamChengYo/AutoPPT-Releases/releases/tag/v0.7.0) 的 `AutoPPT-Setup-0.7.0.exe`，或使用程式內更新。建議建立新專案；既有專案先在視覺風格按「重新規劃設計」，確認後重新生成，讓本次新的設計流程參與整份製作。

- 規劃與製作直接使用固定版本 PPT-Master 的 Planning Core、Executor Core 與 SVG Core；模型可按需搜尋、讀取原始設計模組、風格、圖表與表格範例。
- 設計規劃增加閱讀方式、觀眾收穫、每頁要建立的理解與素材需求；構圖可隨內容改善，保留核准主張與頁序。
- 新簡報預設引導模型每批製作 2–4 頁，一次轉換及匯入，再檢查這批實際 PowerPoint 頁面。複雜頁可單獨製作；修改只重做指定頁面。
- 自動截圖後直接交給模型檢視，重複截圖請求使用快取；舊 SVG 與物件明細從模型歷史壓縮，完整來源仍保存在專案。
- 接入 PPT-Master 原生形狀產生器，支援 Office 箭頭、流程圖與標註等可編輯形狀；增加相容的陰影、光暈及頁內 SVG 引用。
- 批次匯入在隱藏副本操作，成功才替換工作簡報；來源用單一索引原子切換，無效 SVG／失敗的 Office 匯入保留既有原稿。

需要 Windows x64、Microsoft PowerPoint，以及已啟用的視覺模型 API。保留原有專案與加密設定；不修改更新來源。

這是將上游生成核心與設計資源整合到 AutoPPT 工具流程，並非託管 API，也不是上游全部 CLI 功能的完整移植。模板母片安裝、動畫、旁白與原生 chart/table metadata 仍未接入；資料圖表以可編輯圖形表達。

已通過 64 項單元測試、實際 Electron／PowerPoint 流程、批次 SVG 轉換、正式打包版與設定恢復驗證。真實模型速度與設計品質交由使用者測試，本版不宣稱已達成特定倍數或上游範例水準。安裝檔未簽章，未驗證跨版本實際安裝。
